# 🌐 Course 01 — AI Fluency: Framework and Foundations

> [← Back to Master Syllabus](../README.md) · [Next Course: 02 - Building with the Claude API →](../02%20-%20Building%20with%20the%20Claude%20API/README.md)

Learn to collaborate with AI systems effectively, efficiently, ethically, and safely within enterprise and architectural workflows. This course establishes Anthropic's flagship **4D Framework** (**Delegation**, **Description**, **Discernment**, and **Diligence**) and the **Description-Discernment Loop** that form the foundation for all subsequent Claude architecture courses.

---

## 🧭 The 4D Framework at a Glance

```text
               ┌───────────────────────────────┐
               │         1. DELEGATION         │
               │  Decide what to hand to AI    │
               └──────────────┬────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────────┐
        │       DESCRIPTION-DISCERNMENT LOOP        │
        │                                           │
        │   ┌────────────────┐   Prompt   ┌─────┐  │
        │   │ 2. DESCRIPTION ├───────────►│     │  │
        │   │ Frame & Prompt │            │ LLM │  │
        │   │                │◄───────────┤     │  │
        │   └────────────────┘   Evaluate └─────┘  │
        │           ▲               │               │
        │           │    Refine     ▼               │
        │           └─────────┌───────────────┐     │
        │                     │ 3. DISCERNMENT│     │
        │                     │ Verify & Judge│     │
        │                     └───────────────┘     │
        └─────────────────────┬─────────────────────┘
                              │
                              ▼
               ┌───────────────────────────────┐
               │         4. DILIGENCE          │
               │  Govern, Audit, Ethics & Risk │
               └───────────────────────────────┘
```
