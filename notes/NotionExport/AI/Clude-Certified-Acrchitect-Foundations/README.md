## 🎯 Exam Competency Areas Tested

According to Anthropic's official certification requirements, the **Foundations Exam** validates that architects can make informed architectural trade-offs across:

1. **Claude API & Model Capabilities:** Model selection (Haiku, Sonnet, Opus), context window limits, prompt caching, vision, structured output schemas.
2. **Model Context Protocol (MCP):** Designing extensible architectures with standard transports, decoupled tool servers, secure authentication, and resource providers.
3. **Claude Code & Agent Loops:** Autonomous multi-step execution, bash/filesystem access, verification routines, permission boundaries, and CI integration.
4. **Cloud & Enterprise Deployments:** Architectural parity and differences across Direct Anthropic API, AWS Bedrock, and Google Cloud Vertex AI (latency, data residency, compliance, identity).

## 📝 Lesson Structure Standard

All lessons authored in these modules follow the workspace's **Enhanced Hybrid Format**:
- **Stage 0 — Concept Map:** Problem-first framing, prerequisite placement, and architect value.
- **🔑 New Terms:** Plain-English glossary table before any technical usage.
- **Stage 1 — The Simple Idea:** Physical real-world analogy and dedicated `"Aha!"` unlock.
- **Stage 2 — How It Actually Works:** ASCII flowcharts, under-the-hood engine disclosures, trade-offs, and mini-reference tables.
- **Stage 3 — In Practice:** Enterprise production implementation patterns and compliance considerations.
- **⚖️ Variations & When to Use:** Decision matrices comparing competing approaches.
- **🐛 Common Errors & Anti-Patterns:** Root cause and remediation tables.
- **📌 Quick Reference:** Copy-pasteable reference configuration/code with golden rules.
- **🛑 STOP — Self-Check:** Socratic scenario question with collapsible technical breakdown.
